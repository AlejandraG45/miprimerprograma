# Nombre del proyecto
Generador Seguro de Contraseñas

## Autor
Alejandra Guachamin Ayo

## Objetivo del sistema
Analizar el impacto de las nuevas tecnologías y relacionarlo con una necesidad real de seguridad digital. Aplicando conocimientos de diseño, programación y arquitectura de software, desarrollar un sistema funcional que integra contenidos de las cuatro unidades mediante un producto funcional.

## Descripción

Este proyecto consiste en el desarrollo de un programa capaz de generar contraseñas aleatorias y seguras.

El usuario puede seleccionar la longitud y los tipos de caracteres que desea utilizar.  

## Tecnologías

- Python 3
- Visual Studio Code
- Git
- GitHub

## Funcionalidades

- Configurar longitud.
- Seleccionar letras mayúsculas.
- Seleccionar letras minúsculas.
- Seleccionar números.
- Seleccionar símbolos.
- Generar contraseñas aleatorias.
- Generar nuevas contraseñas.

## Ejecución

Para ejecutar el programa se debe utilizar:
python generador_contrasenas_completo.py

Se tiene los avances realizados
Primer avance
python generador_contrasenas_CU01.py
Segundo avance
python generador_contrasenas_inicio.py
