# Generador Seguro de Contraseñas

## Descripción

Este proyecto consiste en el desarrollo de un programa capaz de
generar contraseñas aleatorias y seguras.

El usuario puede seleccionar la longitud y los tipos de caracteres
que desea utilizar.

## Tecnologías

- Python 3
- Visual Studio Code
- Git
- GitHub

## Funcionalidades

- Configurar longitud.
- Seleccionar letras mayúsculas.
- Seleccionar letras minúsculas.
- Seleccionar números.
- Seleccionar símbolos.
- Generar contraseñas aleatorias.
- Generar nuevas contraseñas.

## Ejecución

Para ejecutar el programa se debe utilizar:
Primer avance
python generador_contrasenas.py
Segundo avance
python generador_contrasenas_CU01.py
